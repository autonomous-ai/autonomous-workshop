The Factory handoff's `project.json` now carries the sealed Release page's own
notes beside the identity fields: `summary`, `what_arrives`, `limitations`,
and (for multi-part products) the validated production `parts` names.
Factory's content drafter and its claims auditor read `project.json` in full
as design notes; a bare `{id, name}` left an imported product with no source
text behind any use claim, so every product-page draft failed the copy gate
(Ouray No. 100, 2026-09-05). The adapter authors no words of its own and the
optional prompt field stays empty.
