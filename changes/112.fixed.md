instead of after a fixed `time.sleep(300)`. The product-run skill carries a

printing the exit status and the log's last lines. The agent-notification

background command of the Manager's ends. `AGENTS.md`, `references/make.md`
and the `make-round` skill give the Claude Code form and say never to queue
several waits in one turn; the Codex wording is unchanged. In Broken God run
