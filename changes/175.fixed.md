  issue #165) no longer treats those Components as changed. When the locking
  round's `gen` reported no identity, make_round reads it as the B-rep that
  round's own reproduction build and B-rep bundle logged, so an unchanged
  Component keeps its lock, its review carries and its Interface checks run
  (ADR 0073, issue #175).
