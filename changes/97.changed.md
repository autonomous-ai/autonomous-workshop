- A Workshop Manager's ruling on a Component's Blocked Report now binds that
  Component's Reviewer (issue #97, amending ADR 0081). Each later component
  round writes the Component's decided rulings into its visual packet and
  summary as `rulings` (report, quoted rows, the worker's request, the
  ruling), copied from `measure/blocked-reports.jsonl`, and they join the
  carry key, so an unchanged rerun after a new ruling is reviewed afresh
  without spending a Shape Round. The review request is still the packet
  path and hash.
- A Component Reviewer who thinks a ruling wrong lists it under
  `ruling_disputes` (`{"report", "reason"}`), not `differences`. A Ruling
  Dispute costs no Shape Round, never reaches the worker (the round keeps
  `ruling-disputes.json`), and a review whose only findings are disputes
  agrees. `make_round --record-review` refuses a dispute-only disagreement,
  a dispute naming no ruling of the packet, and a review of a packet
  rendered before the Component's latest ruling; an unreadable ledger
  refuses the component round. `CONTEXT.md` defines Ruling Dispute. Frozen
  runs keep their materialized tool and agent text.
