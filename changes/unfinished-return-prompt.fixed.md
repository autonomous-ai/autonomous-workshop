Tell a continuing native turn how many empty returns this stage subject has
spent and what the next one costs. On the last allowed return the prompt names
the truthful-need finalizer route for that exact stage instead of only
repeating "run the finalizer", so a genuinely blocked Goal records why rather
than repeating a failed repair until a cap ends the invocation. The prompt
reads the same stop condition the loop enforces, so legacy clock and turn-budget
runs are never promised a stop they do not get.
