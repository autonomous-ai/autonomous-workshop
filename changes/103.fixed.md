`check_layout` no longer counts a byte-for-byte copy of the host-installed
print-details library (`features/print_details.py`, 1121 code lines) as an
`oversized-library` in a multi-part project. The Manager may not edit or split
those bytes, so before this fix every multi-part toy using print details failed
final verification (Broken God attempt 18, after all Make work had passed). A
modified copy is still the project's own code and is still counted.
