A Component round no longer runs without its worker nonce when the make_round
guard cannot see the call. In Broken God attempt 18 five worker commands each
edited a part in a `python3 - <<'EOF'` heredoc and ran make_round on a later
line; a quote in the heredoc hid the call, the guard let it run unchanged, and
the rounds' `summary.json` files were later moved out of the product tree, so
Make was accepted without judging them. Now, in a new guarded run:

- the host seals `.agents/MAKE-ROUND-GUARD.json` in the run, and `make_round`
  refuses a component build round without `--worker-nonce`, telling the worker
  to run it as its own plain command;
- the guard denies a command that names make_round and holds a heredoc,
  cannot be parsed, or parses to no call while doing more than read the script
  with `sed`, `grep`, `cat` and the like;
- the `make-round` skill and the `component-worker` prompt say to run
  `make_round` as its own Bash command, never beside a file edit or heredoc;
- Make acceptance refuses a round a Component's `make-round-state.json`
  records whose `summary.json` is missing, naming each one.

Frozen runs keep their materialized guard and tool bytes; a run without the
marker runs component rounds as before.
