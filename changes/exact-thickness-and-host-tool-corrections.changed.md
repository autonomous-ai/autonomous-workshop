# Exact thickness readings; host-corrected run tools

`check_thickness` re-measures every grid reading under the minimum wall
exactly against the mesh, so a wall drawn at the minimum no longer fails on a
grid step or a floating-point digit, while a genuinely thin wall still does.
`workshop resume --refresh-tools` rewrites a run's host-owned domain skills
from the installed Workshop and rebinds them in the run manifest, recorded in
the run's private host state. See ADR 0052.
