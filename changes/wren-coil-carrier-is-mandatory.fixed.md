A Wren Coil Make run shipped a solid crescent ornament with no inlay pocket, no
tap window and no way to get a chip in or out. The run read the Wish as naming
only a shape, concluded the NFC tool domain did not match it, wrote that the
design "does not claim to be a compliant Wren Coil NFC carrier", and built a
single closed solid -- deleting the product rather than narrowing it.

Hosting the inlay is no longer conditional on the Wish mentioning one. Section 1
of the carrier standard -- the one section a run may never depart from -- now
says every release carries an inlay, and that "the Wish did not ask for NFC",
"the object is decorative" and "the tool domain does not match" are Match-stage
selection verdicts stated before geometry exists, never a reason for a Made
object to arrive solid. Taste and skill say the same in their own voice, and a
Wish that names a form rather than a tool now resolves to the smallest honest
duty that form performs instead of dropping the coil.

Service stops being a choice between sealed and serviceable: every carrier
opens. Section 9 is now Access and service, with a declared insertion axis and
sweep, pocket mouth clearance, cover retention, a thumbnail purchase feature, a
refit count, and install-and-removal figures in the manual; bonding, welding and
break-to-open covers are refused. The Make checklist gains a first check that
the carrier set exists in the source as named solids -- inlay datum, pocket,
window wall, keep-out, cover -- which fails on a missing solid instead of
accepting a note explaining its absence, and an access check for the insertion
sweep and the cover. The skill tree is resealed.
