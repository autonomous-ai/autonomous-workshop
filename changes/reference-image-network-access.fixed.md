Let a Wish that names an existing object reach its reference images. The
component-CAD proxy allowed sixteen supplier domains, so every image host was
refused and the visual-reference contract could only record a need and stop --
one live run did exactly that on a Wish that had completed a day earlier. New
runs keep `limited` mode, which allows GET, HEAD and OPTIONS only and refuses a
POST, and widen the domain map; reads reach any host and nothing can be sent
out. The filesystem profile is unchanged. Sessions checkpointed under the
previous map resume through a new rollback step.
