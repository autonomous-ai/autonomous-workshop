Let a Wish that names an existing object find its own reference images when
none are attached. `--ref` stays the preferred path and its sealed bytes still
win, but a Wish that only names an object left the run with nothing to look at
and a text-derived shape does not resemble the named thing. Command networking
keeps `limited` mode, which allows GET, HEAD and OPTIONS only and refuses a
POST, and widens the domain map; reads reach any host and nothing can be sent
out. The filesystem profile is unchanged. Sessions checkpointed under the
previous map resume through a new rollback step. When no reference is reachable
the run labels its interpretation text-derived rather than stopping.
