A native session that fails to start or ends without completing is now a
visible stop. `workshop status` reported such a run as `active`, and Broken
God attempt 16 sat idle for seven hours after Claude Code's weekly limit
refused its resume while status still read the stale `budget` stop from
before a cap raise. The host now records a content-free stop for the exact
checkpoint, so status reads `waiting`. A provider usage limit gets the new
`stop_category` `usage-limit` with a host need to resume after the limit
resets. A budget stop record below the current limit no longer wins. The
durable checkpoint, gates and token accounting are unchanged. See ADR 0050's
amendment.
