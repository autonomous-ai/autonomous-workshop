The Make finalizer no longer refuses the ledgers `make_round` writes. It
refused every `.jsonl` in the product tree, so in Broken God attempt 18 the
Manager moved `measure/blocked-reports.jsonl` into `notes/` by hand, and the
host's Blocked Report check then depended on where it went. The finalizer and
the host's artifact manifest now both keep exactly make_round's ledgers where
it writes them -- `measure/blocked-reports.jsonl`,
`measure/contract-amendments.jsonl`, `measure/shared-helper-freezes.jsonl` and
each Component's `measure/component-rounds/<id>/unlocks.jsonl` -- so Make seals
them and the host's checks read the same bytes. Any other `.jsonl` stays
excluded. Frozen runs keep their materialized finalizer bytes.
