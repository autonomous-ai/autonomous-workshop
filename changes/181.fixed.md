- A `workshop fix` run no longer clones its source's Blocked Report ledger
  into `revision-work/`. The host refused the cloned reports as another
  run's, so Turtle Moods v03's Manager deleted the ledger by hand to get
  Make accepted. The source's ledger now stays only in the read-only
  `revision-source.zip`. In a guarded run, the make_round guard and the host
  also log every read of the run's own ledger, and Make acceptance refuses a
  ledger that was deleted or rewritten after one of those reads. A source
  report that is still open holds nothing in the fix run; if it still
  applies, the worker files it again (ADR 0081, issue #181).
