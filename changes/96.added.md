- A refused in-run Contract Amendment no longer stops the run when its
  Contract Reviewer confirmed the contradiction, found the change invisible
  and only named a smaller change (issue #96, amending ADR 0085). The
  Workshop Manager may propose one Smaller Retry: the same rows, each change
  the refused row text with only words deleted, reviewed by another fresh
  `contract-reviewer`. `make_round --record-amendment-review` prints the
  reviewer's reason and the retry rule, and the retry's proposal and packet
  record `retry_of`.
- `make_round --propose-amendment` and the host's replay before Make
  acceptance refuse a retry that adds or respells a word, a third proposal
  for the same rows, a retry after a contradiction or visibility refusal,
  and a reused reviewer. A refused retry stops the run on the need as
  before. Frozen runs keep their materialized tool and agent text.
