A shape check goes stale only when its Geometry Sources change: each
Component's source, the Shared Helpers it imports and the project parameters.
Adding audits such as `measure/check_landmarks.py` used to stale the motion
evidence and every Coupled Interface check (Broken God attempt 18, about
1.5 h of reruns with no shape changed). The rule is now defined once, in
`cad/scripts/geometry_sources.py`, and read by the motion evidence, the
component and assembly packets, `make_round --interface` (which records the
`sources` it judged) and `verify_project`'s sweep reuse. Measurements,
audits, notes, samples and renders never make a check stale; editing a
Component source or an imported Shared Helper does.
