- A resumed Claude Code session is no longer charged twice against the product
  token budget. A resume's result totals the whole session, and the host had
  added it as one more thread, so Broken God attempt 14 stopped at 86.5M of a
  100M cap with 173M recorded. The ledger now keeps one thread per native
  session (`session_id`, `invocations` in `native-budget.json` and
  `workshop status --json`): a resume replaces its session's charge, never
  lowering it; a new session still adds a thread. Ledgers written before the
  fix keep their recorded value. See ADR 0078's amendment.
