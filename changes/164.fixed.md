- A `workshop fix` run no longer inherits its source run's Blocked Report
  rulings. The cloned `measure/blocked-reports.jsonl` names the source's
  Wish, and its rulings bound every new packet of their Component, so a
  ruling the fix existed to overturn bound the fix run's Component
  Reviewers. Only rulings decided in the run itself now reach a packet,
  the carry key and `--record-review`'s ruling check; one that should still
  hold is decided again on a new Blocked Report (ADR 0081, issue #164).
