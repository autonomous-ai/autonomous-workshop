Writing these surfaced three real bugs in the backward-routing feature from tasks 4.4/4.5, none previously caught: (1) `.agents/product-run/.agents/skills/autonomous-workshop/scripts/stage_proposal.py`'s `playtest` branch hardcoded `transition = "release" if verdict == "pass" else "make"`, never proposing `"concept"` even when feedback invalidated it — any real design-invalidating Playtest turn would have been rejected by the host gate as a transition mismatch; (2) `_ready_contract_artifact`'s call in `_evaluate_playtest_stage` (`src/workshop/workflow/native_run.py`) only allowed `transitions=("release", "make")`, missing `"concept"` — the host gate itself would refuse a `"concept"` proposal as non-canonical even once the finalizer proposed it correctly; (3) `NativeMade.assert_context` in `src/workshop/make/native.py` required `concept.round == expected_round` unconditionally, but a build-only revision (by design) advances Make's round while deliberately leaving the standing Concept — from an earlier round — in force, so this made every build-only Make retry fail closed. Fixed by relaxing the check to `concept.round > expected_round` (still rejects a concept from the future; `concept_sha256` equality remains the real binding check, and it already encodes round in its hash).
