## ADDED Requirements

### Requirement: Real Codex acceptance proves simplified context is sufficient

The opt-in authenticated acceptance tier SHALL require real Codex to discover the frozen simplified capability, author the consolidated Invent source and adaptive visual plan from production context, and invoke the normal finalizer without an overlay that restates either schema. It SHALL then prove that host effects occur after native exit and the same session resumes at Make with unchanged proof, Playtest, Release, and publication boundaries.

#### Scenario: Real Forge Invent finalizes directly
- **WHEN** the first bounded Invent turn creates both complete authored inputs
- **THEN** the production finalizer accepts them and no recovery turn is spent discovering hidden schemas or generating host-owned plumbing

#### Scenario: Recovery receives partial authored state
- **WHEN** the initial bounded turn leaves one complete input and one incomplete or absent input
- **THEN** the same session completes the smallest missing source, attempts finalization next, and does not restart selection or research

### Requirement: Acceptance reports simplified authoring evidence narrowly

The acceptance report SHALL record the capability version, exact stage/session continuity, Invent turn count and duration, first-finalizer success or bounded rejection count, authored-input hashes, adaptive role count, effect-resume behavior, and Make transition. It MUST NOT claim creative quality, image quality, buildability, physical performance, or economic improvement solely from protocol completion.

#### Scenario: Simplified route reaches Make
- **WHEN** authenticated acceptance passes the compound Invent gate
- **THEN** its report distinguishes context-and-integration success from product-quality evidence and preserves bounded diagnostics for any recovered finalizer rejection
