# Mintfin

Digital prototype; geometry and motion verification is incomplete and no print-readiness claim is made.

See [assembly and coupon instructions](mintfin/README.md), [dimensions and verification limits](mintfin/mintfin_spec.md), and [the 75 individual production STEP files](parts/). Each production file represents one piece; use one of each for a full kit. The combined assembled.step is the neutral happy figure, spare sleepy face and three coupon pieces.

Native static validity and interference checks passed for the delivered assemblies and individual pieces. Motion, physical printing, snap compliance, friction, magnetic retention and adhesive strength remain unverified.

Final integrated verification returned UNVERIFIED: build, fit and specification audits passed, but motion exhausted the shared geometry allowance and the subsequent native inspection batch did not run. Earlier static checks remain separate evidence and do not turn this final result into a pass. See `mintfin/measure/verification-pipeline.md` and the sealed geometry notes.
