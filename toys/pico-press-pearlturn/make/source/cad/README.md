# Pearlturn

`pearlturn.step.py` is the sole combined review entry. `part_shell.step.py` and `part_pearl.step.py` are the two printable entries. `pearlturn_lib.py` contains every parameter and builder. `make_states.py` exports exact presentation states from the same builders.

The shell prints on a broad side face and the pearl on one circular end. The pearl is loose and placed in either open lip saddle for play; it is not captured and there is no fit or assembly claim.

Rebuild with the materialized CAD `gen`, `export`, and `verify_project` tools. Printer bed: `--bed 220x220x220`. No STL repair is used.

The 65° state model is deterministic presentation evidence of the intended endpoint relationship. It is not a simulation or physical proof of successful rolling, friction, balance, durability, or repeatability.
