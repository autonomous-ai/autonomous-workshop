# Mintfin source

All parameters live in params.py; hinge/body builders in mintfin_lib.py and head/face builders in head_faces.py. Each part entry builds one connected printable solid at Z0. Combined entry is authored after isolated component passes.

Printer bed declaration: --bed 256x256x256

The chain must retain its delivered arrangement for print-in-place interlocking. Four-color AMS/MMU regions are subdivisions of the fused component entries. Physical release and motion are unverified.
