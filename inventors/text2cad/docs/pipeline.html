One cycle, and where it dies

Trend digest to published product. Every phase is labelled with the file it writes — that file is where you start reading when the run goes wrong.

Read in this order

Where to look when it breaks

  • out/<slug>/postmortem.md — first stop. Cause, phase, cost, what to fix. Written on every DONE and every ABORT.
  • out/<slug>/run.json — per phase: cost_usd, num_turns, max_turns, is_error, plus panel, ship, unjudged_lenses, seed.
  • out/<slug>/gate.json — watertight, bodies, overhang_pct, bridge_span_mm, slice result.
  • CYCLES.md — one row per cycle, every run since the start.
  • logs/cycle-<date>.log — full stdout when the postmortem isn't enough.

Exits

How a run actually dies

  • Discover — no WINNER: line, abort before the build spend.
  • Draft — no _assembled.png: one retry with an export-first note, then the proposal goes out render-less.
  • Build — milestone likeness FAIL sets build_aborted and kills the run at half budget.
  • Gate — not_watertight, bodies=N, overhang, bridge_span>25, slice_failed, footprint or print time.
  • Panel — a crashed lens returns FAIL no output; a lens that never ran is seeded FAIL did not run. Neither reads as silence.
  • Ship — gate PASS with an unjudged lens still holds. An unjudged product is untested, not clean.

Starvation

Turn caps and budgets

  • num_turns == max_turns in run.json means the phase was starved, not broken — it ran out of turns mid-thought.
  • BUILD_TURNS=160 · DRAFT_TURNS=70 · LENS_TURNS=70 · LENS_TURNS_LIKENESS=35
  • REPAIR_TURNS=70 · ARB_TURNS=60 · DISCOVER_TURNS=40 — all env-overridable.
  • Repair tiers: broken 2 · functional 3 · cosmetic 2, plus one bonus pass while the failing lens scores are still climbing.
  • Cycle killed at CYCLE_TIMEOUT_S (6h default); the marker still writes, so the day is spent.
