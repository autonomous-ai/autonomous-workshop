# Cost-Gated Bonus

## Definition
A rule where a random or lucky outcome only grants its extra benefit if the player pays an additional resource cost. It keeps the excitement of getting lucky while taxing how often players can actually capitalize on it, dampening pure-luck swings between players.

- requires:: [[mechanisms/dice-rolling]]
