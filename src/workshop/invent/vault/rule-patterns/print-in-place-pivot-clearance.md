# Print-in-Place Pivot Clearance

## Definition
A pivot printed assembled needs 0.4-0.5mm radial clearance and a seam plane parallel to the build plate; below 0.35mm the sacrificial layer fuses on most FDM printers and the joint never breaks free. Orient so the rotating face is a top surface, and spec the first actuation ("break free by hand before play one") in the rulebook's setup.
