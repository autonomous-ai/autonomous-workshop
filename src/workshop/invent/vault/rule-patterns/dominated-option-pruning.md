# Dominated Option Pruning

## Definition
Compare each option with its closest alternatives across realistic game states. Remove, merge, reprice, or strengthen an option that remains inferior in every relevant state; this reduces content and may sacrifice thematic variety.

## Relations

## Notes
- Retain a weak-looking option only when testing demonstrates a credible situational use.
