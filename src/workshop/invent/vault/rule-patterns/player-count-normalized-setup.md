# Player-Count-Normalized Setup

## Definition
Key quantities such as board space, available actions, neutral obstacles, resources, and objectives are set from a player-count table so that competition and opportunity remain comparable per player. This adds setup rules and count-specific balancing work, and may require extra boards, blocked spaces, or neutral pieces.
