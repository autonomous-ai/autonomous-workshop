# Diminishing Returns

## Definition
Each repeat of the same action or purchase yields less than the one before (rising cost, falling payout). The natural predator of one-trick strategies: the trick still works, it just stops being the only correct move.

## Relations

## Notes
Prefer smooth curves over hard caps — a cap invites playing exactly to it.
- [yt:z7_s7KdrtpA] medium: Dominion slows leaders passively: high-point cards clog the deck's efficiency, so buying victory points early costs future turn quality and lets trailing players' leaner decks catch up. (Adam in Wales - Board Game Design 2016)
