# Explicit Rule Precedence

## Definition
Establish a single hierarchy for resolving conflicts among core rules, cards, scenarios, and player powers. Add deterministic tie-breakers such as prohibitions overriding permissions; this reduces ambiguity but requires careful auditing so the hierarchy does not conceal unintended contradictions.

## Relations

## Notes
- Use precedence for deliberate exceptions, not as a substitute for correcting incompatible rules.
