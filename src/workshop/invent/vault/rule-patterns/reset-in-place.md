# Reset in Place

## Definition
Design the play surface so components return to their starting state through one sweep, tilt, slide, or other constrained motion without being individually collected and placed. Guides, channels, catch areas, and fixed component homes reduce handling, but add physical complexity and may constrain spectacle or layout.

## Relations

## Notes
- A catch feature fails if players must empty it through several separate handling steps.
