# Action Timer

## Definition
A real-time cap on deciding: a sand timer, a turn clock, or any-player-may-flip pressure. Bounds the slowest player's turn instead of everyone's patience.

## Relations
- variant-of:: [[mechanisms/action-timer]]

## Notes
The BGG mechanism of the same name is the general family; this node is the rule clause you paste into a ruleset.
