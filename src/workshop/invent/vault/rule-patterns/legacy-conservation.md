# Legacy Conservation

## Definition
Require each permanent loss of an option, rule, or board feature to preserve a tested minimum decision space or introduce a comparably meaningful replacement. This keeps the campaign transformative without letting accumulated changes hollow out the core game, at the cost of additional branch testing and content.

## Relations

## Notes
- Evaluate the resulting game state, not merely the dramatic impact of the change when it occurs.
- Irreversible changes should usually express player choice rather than compulsory randomness.
