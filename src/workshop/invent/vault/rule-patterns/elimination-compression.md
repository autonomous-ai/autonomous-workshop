# Elimination Compression

## Definition
If a player permanently loses agency, make that event end the game, end a short round, or sharply accelerate the remaining play. This preserves decisive elimination while limiting enforced spectator time, at the cost of constraining match structure and potentially shortening late-game strategy.

## Relations

## Notes
- Giving eliminated players trivial chores does not restore meaningful agency.
