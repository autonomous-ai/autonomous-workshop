# Component-Complete State

## Definition
Audit every rule-relevant fact and assign it a persistent, unambiguous representation on a listed component or in the physical arrangement. Add or redesign markers, tracks, labels, and zones when players would otherwise need to remember or infer that fact; this increases component count and upkeep.
