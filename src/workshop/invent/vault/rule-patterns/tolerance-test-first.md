# Tolerance Test First

## Definition
Before committing a multi-day kit print, print the smallest coupon that exercises the physics the design depends on: the mate pair at three clearances, the topple-critical figure at three step heights, the pivot at three gaps. Every dimension the design marks physics_untested gets its coupon named in print_specs, so the first full print is a confirmation, not an experiment.
