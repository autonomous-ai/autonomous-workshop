# Player-Count Matrix Testing

## Definition
Treat every advertised player count as a distinct balance configuration and repeatedly test each one, especially the minimum, maximum, and structurally awkward counts. This costs substantially more testing time and may reveal that some counts need variants or should be removed from the box.
