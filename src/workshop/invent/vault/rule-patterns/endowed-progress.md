# Endowed Progress Effect

## Definition
A rule clause that starts players with partial credit toward a goal (non-zero progress on a track that needs N to complete) instead of zero. Because players feel already underway rather than starting cold, they perceive completion as closer and stay more motivated to finish. It costs nothing mechanically beyond relabeling the starting state — the remaining effort can be identical to a zero-start design.
