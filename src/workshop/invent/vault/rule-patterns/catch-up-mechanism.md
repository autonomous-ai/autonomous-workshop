# Catch Up Mechanism

## Definition
A rule that hands trailing players a structural edge: cheaper actions, bonus draws, or first pick of a scarce resource. Applied gently it keeps games close without punishing skill; applied hard it makes leading pointless.

## Relations

## Notes
Tune so the leader still wants to lead. Rubber-banding that fully cancels position converts the game into who-peaks-last.

- [yt:F_1YcCcBVfY] medium: Pit Crew replaced 'you lose points for mistakes' with 'opponents gain points when you err' on the same score track — mechanically similar but players stopped resenting their own penalties. (GDC Festival of Gaming 2018)
