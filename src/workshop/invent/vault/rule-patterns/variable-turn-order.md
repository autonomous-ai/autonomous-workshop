# Variable Turn Order

## Definition
Turn order is re-derived each round from game state (last-place first, an order track players bid or pay onto) instead of being fixed clockwise. Removes the compounding value of a permanently early seat.

## Relations

## Notes
Order tracks that players spend actions on turn the fix itself into a decision, which is usually better than a free rotation.
