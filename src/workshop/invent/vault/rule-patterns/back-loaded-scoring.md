# Back-Loaded Scoring

## Definition
Point values or ability strength scale up across game phases so early rounds are a low-stakes warm-up and late rounds carry most of the game's swing. Because the biggest points arrive at the end, a weak start doesn't lock in a loss and trailing players keep a realistic path to victory. Players must know this escalation is coming from the outset, or a late comeback can feel unearned.
