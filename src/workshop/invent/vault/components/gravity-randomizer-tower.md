# Gravity Randomizer Tower

## Definition
Players drop cubes, tokens, or chunky symbol dice through internal baffles and read the pieces that emerge into a tray. It standardizes randomization and can deliberately retain some cubes between resolutions, creating memory and uncertainty. Removable baffle modules make the same shell reusable for different probability profiles.
