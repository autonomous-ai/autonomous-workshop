# Stackable Order Counter

## Definition
A chunky counter carries one coarse symbol through its silhouette, top relief, or socket pattern and can be stacked face-down on a unit peg. Players build concealed or visible action queues, then remove counters in order to resolve them. Keyed backs prevent players from identifying hidden orders by touch unless that is intentional.
