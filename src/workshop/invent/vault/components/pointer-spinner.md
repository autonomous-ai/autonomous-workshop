# Pointer Spinner

## Definition
A balanced pointer rotates around a printed axle above a segmented base and selects a direction, value, or category. Raised dividers and large engraved icons replace fine printed sectors, while a low-friction hub gives sufficiently long spins. Swappable sector rings let one spinner serve several scenarios.
