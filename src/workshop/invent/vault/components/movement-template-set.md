# Movement Template Set

## Definition
Rigid rulers, arcs, forks, and footprints encode permitted movement distances and turning angles. Units align to molded stops or notches, so movement can be measured repeatably without paper rulers or fine markings. Different template silhouettes express speed classes, formations, or special maneuvers.
