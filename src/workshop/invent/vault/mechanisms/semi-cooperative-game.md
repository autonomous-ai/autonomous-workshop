# Semi-Cooperative Game

## Definition
Semi-cooperative games create a framework where players must collaborate to overcome a shared threat or achieve a collective goal, but individual victory conditions allow for both cooperation and competition within the same game. The core tension emerges from the simultaneous need to help others succeed (to avoid mutual failure) while positioning oneself as the ultimate winner through secret objectives, hidden roles, or asymmetric scoring that may conflict with group progress.

## Notes
The mechanism thrives when hidden information prevents alpha-solving but fails if deducible
Success depends heavily on incentive alignment—players must have credible reasons to cooperate even when partially adverse
