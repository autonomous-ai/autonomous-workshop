# Simulation

## Definition
A mechanism where game systems model real-world processes or domains with interconnected rules that create authentic pressures and decisions. Players navigate complex causal relationships—managing resources, understanding cascading effects, and responding to system dynamics—creating tension through the need to reason through intricate interdependencies rather than isolated choices.

## Notes
Simulation's value lies in teaching players what a system feels like; authentic pressure requires sufficient complexity, which can paradoxically make the game harder to play.
Playtesting across multiple strategies and player counts is critical to identify balance failures where the simulation amplifies one viable approach.
