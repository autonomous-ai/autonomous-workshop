# Square Grid

## Definition
A square-tessellated board structure where pieces occupy individual cells and move through adjacent squares in cardinal and/or diagonal directions. Tension emerges from the multiplicity of movement options—players must evaluate positional control, range-of-attack patterns, and cumulative positioning advantage, all of which scale sharply with board size and unrestricted move freedoms.

## Notes
Square grids permit 8-directional movement (4 orthogonal + 4 diagonal) versus hex grids' 6 directions, creating sharper tactical branching and longer decision trees per turn.
Orthogonal-only variants (4-direction) reduce complexity and analysis burden but limit positional nuance.
