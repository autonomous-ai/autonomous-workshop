# Chit-Pull System

## Definition
Players randomly draw cardboard counters (chits) from a container to trigger game effects, activate units, or determine action order. Unlike dice, drawn chits are removed permanently, creating shifting probabilities as the pool depletes. Tension emerges from unpredictable activation sequences and the possibility of one player drawing multiple activations consecutively while opponents wait passively.

## Notes
Distinguishes itself from dice by allowing chits to be removed, making later draws non-uniform and creating natural rebalancing as the pool empties.
Popular in wargames for simulating chaotic simultaneous action on a battlefield without requiring true simultaneity.
