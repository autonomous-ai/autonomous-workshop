# Selection Order Bid

## Definition
Players bid resources to secure their position in the turn order for an upcoming round. As the bid escalates, players can opt to pass and accept a lower position, creating a cost-versus-advantage tradeoff. The tension emerges from balancing the strategic value of turn order (which determines access to choices or actions) against the real cost of outbidding rivals.

## Notes
Works best when turn order provides meaningful but not dominant advantages—if first place is too strong, dominant strategy emerges.
All-pay variants (where losers also pay) intensify resource scarcity and bid evaluation complexity.
