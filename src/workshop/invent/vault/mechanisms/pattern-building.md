# Pattern Building

## Definition
Pattern building is a mechanism where players strategically place components on a shared or personal play area to form specific configurations that trigger scoring or game effects. Tension arises from spatial constraints (e.g., no adjacent duplicate colors/values), limited placement options, and the need to balance immediate scoring against positioning for future patterns. The mechanism rewards forward planning and recognizing how current placements enable or block high-value patterns.

## Notes
Analysis paralysis is common when pattern constraints are numerous or end-game scoring rewards are large; pairing with action-selection/drafting reduces decision space.
Games with transparent pattern layouts (players see all target patterns before play) experience decided-early problems; opaque discovery mechanics create more dynamic decision trees.
