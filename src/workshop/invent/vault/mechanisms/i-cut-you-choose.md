# I Cut, You Choose

## Definition
One player divides a pool of resources into separate groups, then other players choose which group they want first, with the divider receiving the remaining groups. The tension arises because the divider must create reasonably balanced splits to avoid leaving themselves with the worst option, yet still tries to psychologically manipulate opponents into picking suboptimal groups through how the division is framed.

## Notes
- conflicts with solo-solitaire-game: I-cut-you-choose requires two independent decision-makers—one to divide and another to choose—whereas solitaire has only one.
Heavy table talk and bluffing creates interactive tension; players attempt to read whether uneven divisions indicate genuine value differences or psychological manipulation.
Fairness depends critically on shared value assessment—asymmetric information about resource value undermines the mechanism's self-balancing property.
