# Sudden Death Ending

## Definition
A game ends immediately when a specific condition is satisfied rather than after a fixed number of rounds. The condition (objective achievement, random deck trigger, or target elimination) may be player-controlled, partially controllable, or random. Tension arises from uncertainty about when the game will end and whether a player's current strategy will still be viable when termination occurs.

## Notes
Tension is strongest when players can meaningfully influence but not fully control the trigger condition.
Unpredictable game length is acceptable only if players expect variable session durations.
