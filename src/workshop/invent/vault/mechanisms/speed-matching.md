# Speed Matching

## Definition
Players race in real-time to spot and claim pattern matches among visible cards or symbols on the table. Tension comes from the collision between pattern recognition skill and physical speed—faster-reacting players win the matching race, creating a feedback loop where early wins build momentum and reward consistent reflexes over strategic play.

## Notes
Speed matching heavily favors dexterity and reaction time over strategic depth; games using it should assume this defines the skill axis.
The mechanic works best with clear, unambiguous visual patterns to minimize false positives and frustration from missed calls.
