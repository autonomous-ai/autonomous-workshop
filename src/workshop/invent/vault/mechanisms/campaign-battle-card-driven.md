# Campaign / Battle Card Driven

## Definition
Each player holds a hand of cards that are dual-purpose: every card carries both an operations/action value (used to move units, fight, or otherwise act) and a printed one-shot event (often historically or thematically flavored, and frequently more powerful but situational or one-sided). On a turn a player commits a card to either its numeric value or its event, and cards spent for value typically cycle back through a discard/reshuffle while cards spent for their event are usually removed from the game for good. The core tension comes from that dual-use choice repeated across a multi-turn campaign: holding a strong card risks the opponent's matching event landing first, while playing it for value burns a powerful effect you can never use, and hand composition constantly signals (or bluffs) what a player might be planning.

## Notes
Ops-value plays recycle the card while event plays usually remove it permanently, which is the main lever designers use to control how scarce/precious the swingy events feel.
Many events are written for one side only, so in asymmetric or multiplayer campaign variants (e.g. COIN-style systems) they can create kingmaking or lopsided swings if a faction draws a card whose event only helps a rival.
