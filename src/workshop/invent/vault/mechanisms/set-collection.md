# Set Collection

## Definition
Players gather matching or complementary cards/tiles/tokens toward predefined groupings, converting quantity and completeness into victory points or powers rather than valuing pieces individually. Tension arises because desirable pieces are scarce or contested (via a shared market, draft, or draw pool), forcing players to balance specializing in a lucky-early set against diversifying to hedge against being blocked. Scoring is often nonlinear (e.g. triangular growth per set size), which rewards commitment to fewer, larger sets while still leaving smaller sets viable, sharpening the decision of when to stop pursuing one set and pivot to another.

## Notes
Triangular/nonlinear scoring curves are the standard fix for making small sets non-trivial while still rewarding big ones.
Without a shared, contested pool for the target pieces, set collection tends to flatten into parallel private checklist-building with little player interaction.
