# Advantage Token

## Definition
A persistent token that circulates among players, granting its holder the ability to modify or enhance an action before passing to the next player. Tension derives from deciding when to use the advantage versus holding it for a better moment, while opponents gain the same ability when it cycles to them.

## Relations
- risks:: [[anti-patterns/analysis-paralysis]], [[anti-patterns/first-player-advantage]], [[anti-patterns/runaway-leader]], [[anti-patterns/seat-advantage]]

## Notes
Effective when the advantage is small enough that holding it too long becomes costly, creating natural pass-forward pressure.
Design success depends heavily on token circulation rate and whether the holder's window is meaningful but not game-breaking.
