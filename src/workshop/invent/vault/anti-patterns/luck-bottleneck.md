# Luck Bottleneck

## Definition
A single random event that fires only once or twice in a game (e.g. a coin flip for turn order) but disproportionately decides the outcome, unlike repeated small rolls that average out via regression to the mean. It tends to sit at structural chokepoints like initial setup. Fix by increasing how many times the event repeats within a play, or by shortening the game so it can be replayed with sides swapped.
