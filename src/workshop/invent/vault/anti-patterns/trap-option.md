# Trap Option

## Definition
An option no informed player would ever take.

## Relations
- mitigated-by:: [[rule-patterns/state-dependent-tradeoffs]], [[rule-patterns/dominated-option-pruning]]

## Notes
- An option is not a trap merely because it is rarely optimal; the failure occurs when informed play reveals no credible state in which choosing it is rational.
