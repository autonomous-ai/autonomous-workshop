# Rules Overhead

## Definition
The rulebook's exception count outweighs its system: timing windows, keyword interactions, and edge cases that force mid-game lookups. The reference doc stays open on the table all night.

## Relations
- mitigated-by:: [[rule-patterns/single-verb-turn]]

## Notes
the Workshop's `teach` axis scores exactly this; the floor (teach>=7) is never relaxed, and the standing fix is removal, not player aids.

- [yt:ZSVREGmO1Xw] medium: SeaFall front-loaded heavier rules into early campaign sessions, which double as tutorials; the complexity ramp made first impressions flat and confusing before the game paid off. (GDC Festival of Gaming 2021)
- [yt:P3P70PrE8i4] medium: Scythe pulls workers from the same 'produce' action as resources, causing constant rules confusion about worker cost/timing; a separate 'enlist' action for workers would remove the ambiguity. (Stonemaier Games 2022)
