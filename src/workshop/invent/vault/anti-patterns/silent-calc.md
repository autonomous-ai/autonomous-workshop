# Silent Calc

## Definition
The numbers make the choice automatic, so every seat computes the same answer and nobody decides anything.

## Relations
- mitigated-by:: [[rule-patterns/degenerate-strategy-counterpressure]], [[rule-patterns/state-dependent-tradeoffs]]

## Notes
- If arithmetic always identifies one superior move, shortening or automating the calculation removes friction but does not restore agency.
- Uncertainty helps only when players can act on it; randomness alone can replace an automatic choice with a guess.
