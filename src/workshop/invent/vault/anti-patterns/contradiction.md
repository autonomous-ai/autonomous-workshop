# Contradiction

## Definition
Two rules answer the same situation differently.

## Relations
- mitigated-by:: [[rule-patterns/explicit-rule-precedence]], [[rule-patterns/blind-rules-validation]]

## Notes
- Contradictions become more likely when several components can independently override the same core procedure.
