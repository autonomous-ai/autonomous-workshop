# Concept

Owns the deterministic `Concept` handoff contract and the structural rule
checks over its authored brief, research record, and drawing instructions.
The native session researches the Wish, decides the design's physical facts,
and writes one drawing instruction per image role; this package validates
that structure, rehashes the sealed concept tree, and derives the researched
Wish write-back. It does not research, compose a prompt, choose a design, or
judge whether a design is good — it does not implement a research agent,
prompt chain, or image adapter.

Public API: `workshop.concept`.
