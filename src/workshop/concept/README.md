# Concept

Owns deterministic Concept contracts and structural checks. Schema v1 is
compatibility-only. For newly marked Forge and Quest runs, schema v2 is active
inside the existing Invent stage: it binds the exact routed Wish, assignment,
Taste, blueprint, Invented, creative-source, round, and revision identities,
and keeps path-only pre-render source distinct from host-sealed image bytes.

This package does not add a Concept lifecycle stage, resume historical Concept
checkpoints, research, compose, repair, render, inspect pixels, choose a design,
read credentials, call a provider, decide a gate, or perform an effect. Its
evidence proves structure and exact bytes only—not visual quality,
buildability, printability, publication, manufacture, or delivery. The host
composes it into marked Forge/Quest Invent without adding a separate Goal,
turn, checkpoint, or transition. Spark and unmarked historical runs retain
their frozen behavior.

Public API: `workshop.concept`.
