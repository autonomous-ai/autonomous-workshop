How this was measured

Tool spans come from the run's own logs. Each begins with the command and carries a line like (685.9s, exit 0); the file's mtime is when it finished, so the start is the end minus the duration. 716 spans across the two runs.

Carried spans are the ones a correction imports from its source archive. They all share one mtime — the instant the import copied them — so they are drawn as a single block at that instant, not as work this run performed. Their durations are the source run's.

The blind review records no duration, only the frames it was handed and the verdict it wrote. It is drawn as the bracket between those two timestamps, which is an upper bound: other work runs inside that window, and the trace shows it overlapping.

Not measured: model time. It is whatever is left after the tool spans, and it is most of the run. No token record survived — both archives carry TOKENS.json: unavailable.
