# Science proof boundary

The shared science lane may use this conservative, deterministic product-design
mapping when a captured public source does not define a physical scale:

```json
{"model_quantity":"one complete interaction","real_quantity":"one represented relationship","scale_ratio":1.0,"units":"represented relationships per interaction"}
```

The matching simplification and disclosure are exact release inputs:

> The model presents one exact, cited source statement and does not claim unmodeled behavior. It is a qualitative teaching model, not a measurement or prediction instrument.

This mapping is not scientific authority. The phenomenon, model, and teaching
point must still be copied exactly from a separately captured public-source
excerpt. Relabelling these Workshop bytes, publisher, or repository URL does
not turn them into independent authority. Make seals the Invent provider
identity, source metadata, exact excerpts, and their hashes into the product
bundle. Playtest replays that sealed record and rejects a generic lane source unless at least one
distinctive Wish topic occurs in both the exact phenomenon and its authority
excerpt. That lexical match is deliberately not delegated to a language model;
an underspecified or unmatched Wish waits for a trusted Wish-aware science
source instead of guessing.

The bundled public retriever deliberately uses a fixed lane query so it does
not disclose private Wish prose. It therefore cannot promise evidence for an
arbitrary phenomenon. Non-English, underspecified, or unmatched science Wishes
wait at `science-source-relevance` until a trusted Wish-aware source retriever
or an explicit bounded topic is available.

Playtest also checks the exact scale and disclosure, then verifies that the
teaching point and limit appear verbatim in the product text. That final check
is deterministic content coverage—not proof that a person learned, enjoyed, or
understood the toy. A custom science verifier may compute additional checks, but
it cannot replace the source bytes sealed by Invent, substitute source metadata,
or self-report product-text coverage: the common release policy replays all
three from the Made artifact.
