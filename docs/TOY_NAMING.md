# Toy Product Naming Rules — autonomous.ai/toys

Read this before you create, rename or review any product name on the Toys pages. Every product name must follow these rules. When an existing name breaks a rule, change only as much as you need to fix it.

---

## The structure

The default shape is **`[Name] [Product Type]`**: the name first, then the product type in 1–3 words, so shoppers can see what the product is right on the card.

```
[Name]                     → the name already says what it is            → F-14D Tomcat, Pocket Bowling Game
[Name] [Product Type]      → DEFAULT for a coined name: add the type      → Tall Ferris Wheel, Antisol Chess Set
[Name]: [Tagline]          → only when a type word alone is not enough    → Wakoo: Twist-Open Desk Toy
[Series]: [Variant]        → products in a series                        → Moonlit Atlas: Paris City Pack
… (Version)                → version or edition, at the very end          → San Francisco Chess Set (F)
```

### Which shape to pick: decide in this order
1. **Can a shopper tell what it is from the name alone?** Then keep `[Name]`.
2. **If not, does adding one type word from the Rule 5 vocabulary make it clear?** Then use `[Name] [Product Type]`.
3. **If one type word still isn't enough**, because the product needs a short description of what it does, use `[Name]: [Tagline]`.
4. **If it belongs to a series**, always use `[Series]: [Variant]`.

Keep the full name to **about 35 characters** where you can, so it isn't cut off with "…" on product cards.

---

## Rule 1: Title Case only

- Capitalize the first letter of every major word. All other letters stay lowercase.
- Keep these small words lowercase unless they are the first word or come right after the colon: `a, an, the, and, or, of, on, in, to, for, at, by, with`.
- Capitalize both parts of a hyphenated word: `Lamp-Post`, `Print-in-Place`.
- **Never use ALL CAPS** for words or brand names. `QUAYSHIFT` becomes `Quayshift` and `V-LOTUS` becomes `V-Lotus`.
- **The only exception** is official model names, codes and numbers. Keep them exactly as they are: `F-14D`, `A400M`, `U-Boat`, `777`, `F1`, `T-Rex`.

| ❌ Wrong | ✅ Right |
|---|---|
| Robot chess set | Robot Chess Set |
| Hawk automaton | Hawk Automaton |
| QUAYSHIFT | Quayshift |

---

## Rule 2: Unclear names get a product type, or a tagline after a colon

- Names like `Pocket Bowling Game` or `F-14D Tomcat` already say what the product is. Leave them as they are.
- **First choice:** add the product type straight after the name, with no separator: `[Name] [Product Type]`. Take the type word from the Rule 5 vocabulary.
- **Second choice:** use a tagline only when a single type word still doesn't explain the product. Put a colon `: ` between name and tagline. **Don't** use em dashes `—`, en dashes `–`, commas or brackets.
- A tagline says **what the product is**, in 2–4 words: a product type plus at most one descriptor. It is **not** a marketing slogan. Don't use `!`, full sentences or "Give it a twist…".

| ❌ Wrong | ✅ Right | Why |
|---|---|---|
| Tall | Tall Ferris Wheel | The type word alone makes it clear |
| Antisol | Antisol Chess Set | The type word alone makes it clear |
| Shatterline | Shatterline Tic-Tac-Toe Set | The type word alone makes it clear |
| WAKOO — Give it a twist. Wake up a friend. | Wakoo: Twist-Open Desk Toy | It needs a short description, so it gets a tagline |
| Nimbo — The Bot Who Waters Clouds | Nimbo: Cloud-Watering Automaton | It needs a short description, so it gets a tagline |
| Frog Snap: Catch the Fly! | Frog Snap: Reflex Tabletop Game | The slogan becomes a product description |

---

## Rule 3: Versions and editions go in parentheses at the end

- Write the version or edition in parentheses at the very end: `(F)`, `(2030)`, `(V2)`.
- Don't put versions anywhere else in the name: no `v01`, no version number at the start.

| ❌ Wrong | ✅ Right |
|---|---|
| Beaver Coaster Keeper v01 | Beaver Coaster Holder (V1) |
| 2030 San Francisco Chess Set | San Francisco Chess Set (2030) |

---

## Rule 4: 5 words or fewer

- Count every word in the full name, tagline included. Numbers and hyphenated words count as one word each. The `(Version)` tag doesn't count.
- **Aim for 5 words or fewer.**
- 6–7 words is allowed only when there is truly no shorter way. It should be rare, not the norm.
- Never go over 7 words.
- Cut adjectives, materials and sizes first. Those belong in the description.

| ❌ Wrong | ✅ Right |
|---|---|
| Victorian lamp-post headphone stand on a paving-slab tray | Victorian Lamp-Post Headphone Stand |
| Sandwalker — 15-Leg Jansen Linkage Walker | Sandwalker: Jansen Walking Machine |
| Desktop Model Rocket on Launch tower | Rocket Launch Tower Model |
| Fidget Spinner Planetary Gear System | Planetary Gear Fidget Spinner |

---

## Rule 5: One product type, one word

Products of the same kind use the **same type word**, always at the end of the name or tagline. Use this vocabulary. Add a new term only when no existing one fits, and then add it to this list.

| Product kind | Use exactly | Don't use |
|---|---|---|
| Any chess or chess-like board set | **Chess Set** | Chess, chess set, Chess Game |
| Board, dexterity and tabletop games | **Tabletop Game** | Table Game, Game Set, Toy (for games) |
| Small handheld games and toys you flick or launch | **Game** (e.g. `Pocket Bowling Game`) | Toy, Hooping |
| Hand-crank or push-along moving figures | **Automaton** | automaton, Walker (as the type word) |
| Walking-linkage machines | **Walking Machine** | Walker, Linkage Walker |
| Small desk play pieces with one action | **Desk Toy** | Desktop Toy, Fidget |
| Spinners, cubes, braids for fidgeting | **Fidget Toy** (or the specific item: `Fidget Spinner`, `Infinity Cube`) | System |
| Static display pieces and statues | **Desk Sculpture** | Display Piece, Statue |
| Scale vehicles and aircraft | **Model** | Model Kit, Replica |
| User-assembled printed kits (sheets, loose parts, Manual) | **Build Kit** (e.g. `Amsterdam Canal Build Kit`) | Kit, Assembly Kit, DIY Kit |
| Moonlit Atlas add-ons | **City Pack** (`Moonlit Atlas: [City] City Pack`) | Pack, Set |
| Desk organisers | **Pen Cup**, **Catchall**, **Holder** | Keeper, Caddy |
| Lights | **Night Light**, **Tea Light Holder** | Lamp (for these) |
| Vases | **Bud Vase** | Vase Holder |
| Keyboard keycaps | **Keycap Set** | Keycaps |
| Book page holders | **Page Holder** | Thumb Page Holder |

---

## Rule 6: Series and variants

- Products in one series use `[Series]: [Variant]`, and the series name never changes.
  - `Moonlit Atlas: Pop-Up City Book`
  - `Moonlit Atlas: Paris City Pack`
- Colour or pattern variants of one product use the same pattern: `Swivel Page Holder: Moon Phases`.
- A spin-off of another product uses its own name plus a tagline. **Don't** use a comma: write `Flexi Axolotl: Mintfin Edition`, not `Flexi Axolotl, dressed as Mintfin`.

---

## Rename with as few changes as possible

When fixing existing names:
1. **Keep the original words wherever you can.** Change only what breaks a rule.
2. **Never rename a product that already passes every rule.**
3. **Don't touch the URL slug.** Only the display name changes.
4. **Keep official and licensed-style names as they are**, for example `F-14D Tomcat` and `A400M Atlas`.

---

## Checklist: run on every name before publishing

- [ ] Title Case, no ALL CAPS (except official model codes)
- [ ] 5 words or fewer (7 at most, and only rarely)
- [ ] Name alone is clear. If it isn't, add `[Product Type]` first, and use `: Tagline` only when a type word isn't enough
- [ ] Around 35 characters or fewer where possible
- [ ] Tagline is a product description, not a slogan: no `!` and no full sentence
- [ ] The only separator is the colon. No `—`, `–` and no commas
- [ ] Version, if any, is at the end in `( )`
- [ ] Product type word matches the Rule 5 vocabulary
- [ ] Series products start with the exact series name
