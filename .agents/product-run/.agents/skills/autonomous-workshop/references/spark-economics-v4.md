# Frozen Spark economics profile v4

This immutable marker freezes the Codex Manager's low reasoning-effort profile,
a 192,000-token automatic context-compaction ceiling, and a 20-minute native
turn boundary for a new Spark run. It replaces v3, which was identical except
for a 64,000-token compaction ceiling. Runs frozen at v1, v2, or v3 keep their
historical ceiling on resume. The same settings apply to Make and Release
because one native session spans the whole Wish. A timeout safely reaps only
the current launcher process; Workshop resumes the exact checkpointed session,
stage packet, Goal, and workspace. It does not create a replacement session or
weaken a gate.

The wider ceiling is working memory, not permission to read more. A 64,000-token
ceiling holds a simple product's whole Make but compacts a complex one every few
requests, and each compaction drops the state the Goal had just established: the
stage packet, the sealed concept, which checks already passed, which repair was
already tried, and what a tool's contract actually is. The run then re-reads the
same bytes and repeats the same failed repair. Room to keep that state is the
only thing this profile adds.

Twenty minutes is a critical-path boundary, not a quality budget. Before it,
the root Manager must establish a real candidate, use narrow checks, obtain the
required bounded blind review, perform at most one coherent visual repair, run
one final integrated verifier, and finalize. Do not make completion depend on
an open-ended child agent. If recovery is needed, inspect the exact remaining
contract and finish it from existing bytes; do not restart modeling, exports,
verification, or review that already passed.

Treat exact workspace bytes, `STAGE.json`, sealed contracts, and concise review
evidence as durable memory. Batch independent reads and deterministic checks.
Do not regenerate unchanged artifacts or use the full verifier as an iteration
loop.

This profile changes cognitive spend, not product authority. Spark still owns
one memorable signature interaction, uses the selected Inventor's exact Taste,
passes every full-tier CAD and manual gate, and requires authenticated Factory
publication. A failed artifact is repaired; no check, evidence requirement, or
truthful limitation is waived to meet the boundary.
