# Frozen Spark economics profile v2

This immutable marker freezes the Codex Manager's low reasoning-effort profile
and a 64,000-token automatic context-compaction ceiling for a new Spark run.
The same settings apply to Make and Release because one native session spans
the whole Wish. Compaction preserves that exact session and its durable files;
it does not create a new stage session or alter host authority.

Treat exact workspace bytes, `STAGE.json`, sealed contracts, and concise review
evidence as durable memory. After a major tool-heavy milestone, leave the
current product state and next concrete action explicit in those files so a
compacted session can continue without repeating exploration. Batch independent
reads and deterministic checks, and do not regenerate unchanged artifacts.

This profile changes cognitive spend, not product authority. Spark still owns
one memorable signature interaction, uses the selected Inventor's exact Taste,
passes every full-tier CAD and manual gate, and requires authenticated Factory
publication. A failed artifact is repaired; no check, evidence requirement, or
truthful limitation is waived to meet the budget.
