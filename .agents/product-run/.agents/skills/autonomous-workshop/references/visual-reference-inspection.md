# Inspect available visual references

Use this reference when the Wish supplies images or asks for the likeness of
an existing object, character prop, or design. An original design without a
visual target does not need image search merely to satisfy this instruction.

## Before committing the form

Prefer user-supplied images. If only an existing object is named, make a bounded
search for useful official or manufacturer images with the available native
tools. Open the actual image at a useful resolution; search snippets, page text,
alt text, and remembering the object do not count as visual inspection.
Stop searching once the views resolve the important visible features.

Record the source URL or supplied filename, which images were actually viewed,
and their relevant observations in the existing research/brief evidence. Keep
accessible local copies when permitted and useful for later comparison. Do not
claim an image was inspected if retrieval or viewing failed. If useful images
remain unavailable, record that limitation and label a permitted approximation
as text-derived. If exact visual correspondence is required and cannot be
verified, use the existing need path; never silently downgrade the Wish.
For a named replica or likeness request, do not treat the absence of the word
"exact" as permission to substitute a text-derived interpretation. Without a
usable reference, request the missing reference through the existing need path
unless the Wish explicitly permits approximation.

Distinguish what the image shows from design assumptions: overall proportions,
feature count and placement, left/right orientation, curve or emblem direction,
and the pattern of visible seams. Do not treat a seam as proof of a working
joint, infer hidden internals, or assign exact millimetres from an unscaled
image. Record conflicts between references; follow the user's selected version
instead of mixing different variants. Use the CAD skill's applicable
image-derived planning and verification path; these notes do not replace it.

## During Make and review

Inspect the early blockout from a viewpoint comparable to the reference. Use
front or orthogonal views and detail crops for asymmetric emblems, small curves,
and seams that a hero angle can conceal. Record each important match, mismatch,
and unobserved area in the existing early-proof finding before adding detail.
A matching silhouette alone does not establish matching surface features.
Derive a compact feature checklist from the inspected reference: include
directional/asymmetric details and each materially different visible face.
Unseen faces remain unverified, not matching by assumption. Carry these features
into the existing critical-form requirements, rather than collapsing them into
one generic "recognizable object" requirement. When print checks require repair,
try changing groove section, depth or print orientation while preserving the
required pattern; do not silently delete distinguishing details to earn a pass.

Keep the independent critic's first pass blind: candidate renders only, without
the target name, source images, intended answer, or inherited target context.
Preserve that response before revealing the Wish, concept, and inspected
reference images. In the revealed pass compare the relevant visual features
explicitly, not just whether the object is broadly recognizable. Put actual
requirements and discrepancies in the existing critical-form evidence; do not
add fields to the frozen review schema or add critic rounds. Changed geometry
still needs current review evidence under the existing contract.

References support visual correspondence, not printability, strength, or
mechanical operation. Keep deterministic geometry and manufacturing checks.
