# Frozen Spark economics profile v1

This immutable marker freezes the Codex Manager's low reasoning-effort profile
for a new Spark run. The same setting is reused across Make and Release because
one native session spans the whole Wish. Forge and Quest retain the high
reasoning profile, and older runs without this exact marker resume with their
original profile.

The profile changes cognitive spend, not product authority. Spark still owns
one memorable signature interaction, uses the selected Inventor's exact Taste,
passes every full-tier CAD and manual gate, and requires authenticated Factory
publication. A failed artifact is repaired; no check, evidence requirement, or
truthful limitation is waived to meet the budget.
