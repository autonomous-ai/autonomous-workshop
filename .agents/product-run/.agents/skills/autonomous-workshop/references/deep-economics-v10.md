# Frozen Forge and Quest economics profile v10

This immutable profile keeps v9's 256,000-token compaction ceiling, one native
Codex thread, and one Goal per active stage while correcting two production
findings from `wish-20260831-123720-43b4ec40`.

Complete-roster routing is index-first. `STAGE.json` contains a compact
`inventor_discovery_index` deterministically derived from every bound
Inventor's exact Taste header. Invent ranks the full index, reads only the best
three full custom-agent TOMLs, selects one, and loads that Inventor's bound
method. It never dumps or rereads the entire full roster. Invent begins at high
reasoning for 20 minutes; bounded medium recovery has 10 minutes and seals the
strongest durable source instead of restarting.

Make evidence distinguishes product state from camera angle. The 16-minute
medium proof turn creates shared `review/early-proof/proof.py` plus
`state-0.step.py`, `state-1.step.py`, and `state-2.step.py`. It generates and
exports all three exact states, then uses `render_product --state-sheet` with
the three state STLs at one fixed view. The deterministic renderer rejects
visually indistinguishable frames. A `--motion-sheet` rotates one unchanged
mesh and is never evidence of a mechanism state transition.

The proof turn keeps v9's action discipline: create or continue the Make Goal
without `get_goal`; batch the root, Workshop, Make, STAGE, and sealed-concept
reads once; do not load the broad CAD skill, optional references, `--help`, an
empty tree, or an early critic; author the helper and three state entries in
the next edit. Inspect the held image and every state frame. One focused repair
is allowed. `finding.json` records what is visibly distinct in each frame and
whether the Wish's form, subjects, action, and relationship survive.

The host accepts `.make-proof-ready.json` only when the exact checkpoint marker
is canonical and the helper, three state sources, three STEP files, three
distinct STL files, held image, signature sheet, and finding are stable regular
files in the round's early-proof directory. This remains a turn marker, never a
stage proposal or quality waiver.

After proof, the first high-reasoning final-Make continuation has a 15-minute
source-handoff boundary. Its first bounded read contains only `STAGE.json`, the
proof source/finding, the current Make reference, and the CAD skill. The next
action writes the complete final product source by reusing the proof. Before
that edit it does not plan, search APIs, inspect tool source, read optional CAD
references, invoke help, or rediscover assembly helpers. Direct build123d
shapes and labeled `Compound` children are the default fast baseline.

If the handoff boundary is reached, all bytes remain durable and normal
30-minute recovery continues the same Goal. Recovery writes missing source
first, then repairs only concrete preflight, state-render, review, integrated
verification, or finalizer failures. The final independent hash-bound critic
remains mandatory. Playtest and Release use medium reasoning and normal
30-minute turns. Every deep stage compacts at 256,000 tokens, and one
Wish/resume invocation may launch at most eight turns.

Lower spend counts only when the exact toy is distinctive, desirable,
truthful, gate-complete, publicly verified, and archived. This profile never
waives Wish fidelity, Inventor Taste, full-tier CAD checks, Quest Playtest,
manual quality, authenticated Factory publication, or GitHub snapshot
integrity.
