# Selectable effort routes v1

This immutable run capability means the host checkpoint freezes exactly one
named effort route for the run. Optional stages pass through without a native
turn, artifact, gate, or evidence claim.

- `spark`: `Wish -> Make -> Release`
- `forge`: `Wish -> Invent -> Make -> Release`
- `quest`: `Wish -> Invent -> Make -> Playtest -> Release`

Inventor selection belongs to the first enabled creative stage. `spark` seals
its selection and compact concept together with Make; `forge` and `quest` seal
selection together with Invent. The trusted host validates every exact binding.
