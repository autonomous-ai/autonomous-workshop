# Frozen Forge and Quest economics profile v6

This immutable marker freezes an artifact-phased Codex profile for new Forge
and Quest runs. One persistent Codex thread and one active stage Goal remain
bound to the complete profile. A turn boundary never advances a lifecycle
stage or weakens a gate.

Invent begins at high reasoning with a 20-minute boundary. If that turn times
out, bounded recovery uses medium reasoning for 10 minutes and must seal the
strongest viable source already developed instead of restarting selection,
research, exploration, or subagents.

Make begins with an eight-minute medium-reasoning proof turn. Its only job is
to persist the smallest exact causal/kinematic proof, neutral held/signature
blockout images, and one independent blind review under the declared CAD
project at `review/early-proof/`. After reading the mandatory root and
current-stage instructions once, do not enumerate or reread skill trees, open
optional CAD references, invoke tool help, or delegate before working proof
source exists.

The proof source defines exactly one module-scope `gen_step()` and returns its
build123d shape. The host prompt supplies complete commands prefixed by the
exact `$WORKSHOP_PYTHON`; CAD package directories are never executed directly
and `python -m` discovery is unnecessary.

When the proof and its review are durable, write the exact checkpoint-bound
`.make-proof-ready.json` described by the host prompt. The launcher treats that
file only as a voluntary native-turn completion marker. It ends the proof turn
and resumes the same Make Goal at high reasoning with a normal 30-minute turn.
It is not a stage proposal, aesthetic gate, lifecycle transition, or evidence
waiver. Only `agent-outcome.json` from the real Make finalizer can propose a
stage transition.

Before reveal, one bounded independent native visual critic receives only the
exact held and signature blockout images and records the unprompted object,
volumetric form, obvious control, action, and spatial or causal relationship.
Only then does it receive the Wish and sealed concept and compare every
explicit positive and negative held-form requirement plus the anti-generic
signature. A generic, plaque-like, board-like, box-like, container-like, or
exposed-mechanism reading fails. Repair and rerender once at most before
marking proof ready.

After the proof turn, high-reasoning Make reuses those exact parameters and
source, persists the smallest complete product baseline immediately, and
follows one funnel: generate and inspect the baseline, run all-printable
preflight, create final renders, perform the required final hash-bound blind
review, make one focused repair at most, run one integrated final verifier, and
invoke the Make finalizer. Do not return to broad exploration or tool-interface
discovery.

Every stage compacts at 24,000 tokens. Playtest and Release use medium
reasoning and normal 30-minute turns. One `workshop wish` or `workshop resume`
invocation may launch at most eight native turns across all stages.

Use these exact CAD command shapes:

```bash
"$WORKSHOP_PYTHON" .agents/skills/cad/scripts/gen <entry.step.py> --write
"$WORKSHOP_PYTHON" .agents/skills/cad/scripts/export <entry.step> --stl
"$WORKSHOP_PYTHON" .agents/skills/cad/scripts/render_product <entry.stl> \
  -o <cad-project>/review/early-proof/held.png \
  --motion-sheet <cad-project>/review/early-proof/signature.png \
  --motion-angles=-12,0,12
```

After proof, iterative preflight is `"$WORKSHOP_PYTHON"
.agents/skills/cad/scripts/verify_project <cad-project> --print-preflight`
without `--fresh`. The trusted host owns the authoritative isolated fresh
rebuild.

This profile does not waive Wish fidelity, Inventor Taste, full-tier CAD
checks, Quest Playtest, manual quality, authenticated Factory publication, or
GitHub snapshot integrity. Lower spend counts only when the exact product is
distinctive, desirable, truthful, gate-complete, publicly verified, and
archived.
