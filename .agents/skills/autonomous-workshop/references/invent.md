# Invent contract

The host supplies the exact Wish and assignment, Taste, lane blueprint, native
session identity, absolute workspace, durable checkpoint, research policy,
capability limits, and current authorization scope. Verify them before acting.

## Work

Explore materially different directions, research with native search when the
concept needs current or factual support, select one direction, and improve it
against the fixed goal. Save the concept, decisions, assumptions, and source
provenance as files. Do not claim geometry, safety, movement, fit,
printability, or player response that has not been checked.

## Artifact and gate

Leave a bounded chosen concept bound to the Wish, Taste, and lane, including
its score and target. Return only compact paths, hashes, gate evidence, needs,
and a proposed transition. The host validates the canonical `Invented`
contract and content hash. Make begins only when the fixed Invent goal is
reached.
