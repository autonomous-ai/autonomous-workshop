# Invent contract

Read `STAGE.json`. Its inputs bind the exact Wish, Match assignment, selected
Taste, lane blueprint, canonical output path, and current checkpoint. Verify
those bytes before acting.

## Work

Explore materially different directions, research with native search when the
concept needs current or factual support, and choose the direction that best
fits the Wish, selected Taste, lane blueprint, and feasible Make capabilities.
Save the concept, decisions, assumptions, and source provenance as files. Do
not claim geometry, safety, movement, fit, printability, or player response
that has not been checked.

The root Workshop Manager may delegate this specialist work to a native
Inventor subagent briefed from the exact selected persona bundle. That
specialist may follow its declared Codex skills and invoke their declared
scripts or deterministic tools. The root Manager reviews the result and alone
creates the stage proposal; inventor code and child-agent output cannot pass
the gate.

## Artifact and gate

Write one authored JSON source with exactly `concept` and `research`, then run:

```bash
python .agents/skills/autonomous-workshop/scripts/stage_proposal.py \
  --run-root . invent --source <invent-source.json>
```

The finalizer binds the chosen concept to the exact assignment and writes the
canonical `artifacts/invent/invented.json` plus `agent-outcome.json`. It does
not assign a numeric quality score. The host validates the contract and exact
hash before Make begins.
